# همکاره

نسخه وایت‌لیبل وب‌سایت و بات‌های همکاره برای استقرار مستقیم روی Cloudflare Pages و VPS.

## امکانات

- رابط فارسی RTL و کاملاً واکنش‌گرا
- فرم ثبت درخواست و ارزیابی اولیه
- تولید کد پیگیری امن و جلوگیری از ثبت تکراری
- پیگیری نتیجه با کد اختصاصی و چهار رقم آخر موبایل
- اتصال Cloudflare Pages Functions به D1
- برند، لینک دانلود، پشتیبانی، پیگیری و پیام‌رسان‌ها از تنظیمات مرکزی
- اعتبارسنجی سمت کاربر و سرور، محدودسازی درخواست و خروجی امن
- منوی شیشه‌ای کامل برای تلگرام و بله
- جداسازی قطعی منوی کاربر و مدیر با allowlist شناسه عددی
- آمار و توقف ثبت‌نام در بات؛ تعویض و rollback امن APK از پنل خصوصی وب
- اعتبارسنجی ساختار و امضای APK، قفل تک‌نویسنده، بکاپ خودکار، جایگزینی اتمیک و ثبت audit
- تطبیق SHA-256 فایل منتشرشده با همان لینک ثابت عمومی و QR قابل اسکن
- دانلود وایت‌لیبل `hamkare.apk` با cache کوتاه، ETag و قابلیت ادامه دانلود

## استقرار

شاخه Production برابر `main`، پوشه خروجی `/` و Build command خالی است. Binding دیتابیس D1 باید با نام `DB` در Cloudflare Pages تعریف شود و migration موجود در `migrations/001_create_registrations.sql` اجرا شود. جزئیات کامل در [DEPLOYMENT.md](DEPLOYMENT.md) قرار دارد.

## مدیریت اپلیکیشن و گزارش تلگرام

در نسخه نهایی، بات استخدامی تلگرام `@Pasokh313e_bot` و بات بله به فایل APK دسترسی مستقیم ندارند. مدیریت توکن بات اختصاصی آپلود، شناسه مدیران، چت گزارش، کانال‌های مجاز، آپلود مستقیم APK و rollback از پنل خصوصی `https://seskia.online/admin.php` انجام می‌شود. پنل تنظیمات موجود `/var/lib/seskia/config.json` و webhook موجود `/telegram.php` را به‌روزرسانی می‌کند و هیچ فایل یا تنظیم Bale را تغییر نمی‌دهد.

نصب یا ارتقای پنل روی VPS:

```bash
sudo bash install-seskia-admin-panel.sh
```

نصاب از پنل قبلی و config بکاپ می‌گیرد، رمز فعلی را حفظ یا به‌صورت مخفی تعویض می‌کند و در خطا فایل‌های قبلی را برمی‌گرداند. در همان تراکنش، آپلود APK را فقط در `telegram.env` بات استخدامی غیرفعال و فقط سرویس تلگرام را restart می‌کند؛ `bale.env` و سرویس بله خوانده یا نوشته نمی‌شوند. APK فقط پس از بررسی ZIP، تطبیق گواهی امضا با نسخه رسمی فعلی، رد کلید تست Android، SHA-256 و تطبیق لینک عمومی منتشر می‌شود؛ ده نسخه آخر برای rollback نگه‌داری می‌شوند.

با Bot API عمومی تلگرام، دریافت فایل ارسالی توسط بات حداکثر ۲۰ مگابایت است؛ مسیر تلگرام همین محدودیت را دارد، اما آپلود مستقیم پنل وب تا ۲۰۰ مگابایت را می‌پذیرد.

نصب بات‌ها:

```bash
sudo bash deploy-hamkare-bots.sh
```

شناسه‌های مدیر، توکن‌ها و گروه‌های گزارش بات‌های استخدامی در زمان نصب دریافت می‌شوند و فقط در فایل‌های env با دسترسی `0600` روی VPS قرار می‌گیرند. توکن بات مخصوص APK و چت گزارش آن فقط از پنل خصوصی و config محافظت‌شده Seskia مدیریت می‌شوند.

هیچ توکن، رمز یا کلید محرمانه‌ای داخل مخزن نگهداری نمی‌شود.
