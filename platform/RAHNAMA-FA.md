# راهنمای پنل مدیریت

نشانی ورود: https://etebarami.net/panel/admin/login

با نام مدیر تنظیم‌شده و رمز اولیه وارد شوید. در صفحه «حساب» رمز اختصاصی حداقل ده‌کاراکتری تعیین کنید. تغییر رمز، نشست‌های قبلی مدیر را لغو می‌کند.

## اتصال ربات و مخاطب‌ها

در «کانکتورها» تلگرام یا بله را انتخاب کنید و توکن ربات خودتان را در فرم همان صفحه وارد کنید. توکن را در پیام، عکس یا گزارش ارسال نکنید. پنل توکن را رمزنگاری می‌کند. ربات باید در گروه یا کانال مقصد عضو باشد و اجازه ارسال داشته باشد. پس از افزودن ربات، عضویت گروه/کانال باید به پنل برسد؛ در صورت نیاز ربات را از مقصد حذف و دوباره اضافه کنید.

کاربر خصوصی با فرستادن /start عضو دریافت پیام می‌شود و با /stop انصراف می‌دهد. ورود فایل CSV به‌تنهایی اجازه ارسال خصوصی ایجاد نمی‌کند. فقط اطلاعات مخاطب‌هایی را وارد کنید که مجاز به نگهداری آن هستید.

در «کمپین‌ها» مخاطب خصوصی یا گروه‌ها/کانال‌ها را انتخاب کنید. پیام گروه در همان گروه منتشر می‌شود. «دکمه عضویت» مخاطب را به صفحه شروع ربات هدایت می‌کند. پاسخ خودکار Business، مشتری را وارد فهرست بازاریابی نمی‌کند.

## انتشار اپلیکیشن

در «وظیفه‌ها»، وظیفه انتشار APK را فعال کنید. نام اپ، نسخه و آدرس لوگو را وارد کنید. آدرس انتشار پیش‌فرض https://etebarami.net/x/publish.php است. برای همین هاست، کلید انتشار را خالی بگذارید تا کلید تنظیم‌شده سرور استفاده شود. کلید سفارشی تنها زمانی کار می‌کند که با تنظیمات دریافت‌کننده یکسان باشد.

فایل نهایی APK را از سازنده اپ تحویل بگیرید. یا لینک مستقیم آن را در «آدرس دریافت» قرار دهید و اجرا کنید، یا خود فایل را در فرم آپلود بفرستید. محدودیت آپلود PHP هاست ممکن است از سقف برنامه کمتر باشد. وضعیت و لینک هر اجرا در تاریخچه همان صفحه نمایش داده می‌شود.

برای تحویل اختیاری لینک، شناسه کانکتور و شناسه چت/کانال مجاز را وارد کنید. مقصد باید به ربات اجازه ارسال داده باشد. این تنظیم، رضایت برای بازاریابی خصوصی ایجاد نمی‌کند.

لینک عمومی ثابت آخرین نسخه: https://etebarami.net/x/dl.php

دکمه دانلود فعلی سایت /x/ باید به این لینک اشاره کند. فایل index.php فعلی در مخزن نیست؛ بدون دیدن آن تغییر داده نشده است. در File Manager فقط آدرس لینک همان دکمه را تغییر دهید؛ باقی فایل را حفظ کنید.

## اجرای مداوم

بهترین روش روی cPanel، یک Cron Job دقیقه‌ای برای اجرای `php /home/CPANEL_USER/platform/cli/worker.php` است. مسیر PHP و نام حساب را از هاست بگیرید. جایگزین GitHub هر پنج دقیقه endpoint محافظت‌شده cron را فراخوانی می‌کند؛ زمان‌بندی GitHub ممکن است تأخیر داشته باشد و workflow زمان‌بند باید در شاخه پیش‌فرض فعال باشد. اجرای سوار درخواست فقط وقتی بازدید وجود دارد مفید است و جای cron دائمی را نمی‌گیرد.

کلیدهای هاست فقط در GitHub Actions Secrets تنظیم می‌شوند: CPANEL_USER، CPANEL_PASSWORD و ADMIN_PASSWORD. اطلاعات محرمانه را در کد وارد نکنید. فایل تنظیمات و دیتابیس داخل platform و بیرون public_html نگهداری می‌شوند؛ از config و storage نسخه پشتیبان امن بگیرید. کلید رمزنگاری storage/app.key را همراه دیتابیس حفظ کنید.

## امکانات و محدودیت‌ها

کد موجود شامل ورود مدیر، مخاطب‌ها، کانکتورها، کمپین، دستگاه‌ها و سشن‌ها، تاریخچه اجرا و انتشار فایل APK است. اجرای واقعی کانکتورها به توکن معتبر و دسترسی رسمی مقصد وابسته است. تست‌های خودکار Bot API را با ترنسپورت آزمایشی بررسی می‌کنند؛ موفقیت آن‌ها به معنی آزمایش ربات واقعی مشتری نیست.

این سامانه فایل APK آماده را منتشر می‌کند و اپ را کامپایل نمی‌کند. ربات با Bot API نمی‌تواند ربات دیگری را کنترل کند یا دکمه‌های آن را بزند. ارسال خصوصی بدون شروع ربات توسط مخاطب پشتیبانی نمی‌شود.

پایگاه‌داده آزموده‌شده SQLite است. صرف تغییر DB_DSN برای اعلام پشتیبانی MySQL کافی نیست؛ مهاجرت‌ها و SQL فعلی باید جداگانه برای MySQL سازگار و آزموده شوند.
