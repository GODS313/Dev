# وب‌سایت VPN Max — نسخهٔ cPanel

## نصب

1. ZIP را در public_html یا پوشهٔ دامنه استخراج کن.
2. در مرورگر مسیر /admin.php را باز کن.
3. رمز مدیر حداقل ۱۲ نویسه‌ای بساز.
4. در پنل، لینک APK یا فایل اپ را تنظیم کن و توکن تلگرام و Chat ID را در صورت نیاز وارد کن.
5. برای حفظ امنیت، لینک اشتراک و توکن‌های خصوصی در این نسخهٔ GitHub قرار ندارند؛ پس از نصب، لینک اشتراک را فقط از پنل مدیریت تنظیم کن.
6. گزارش تلگرام با رضایت اختیاری کاربر ارسال می‌شود.

## امکانات

- صفحهٔ فارسی و واکنش‌گرا با داشبورد شبیه اپ موبایل با تم روشن آبی‌بنفش و دانلود اپ
- خواندن فهرست کانفیگ از لینک اشتراک HTTPS
- انتخاب تصادفی یک آدرس کانفیگ و تخصیص یک‌باره به هر شماره
- جلوگیری از تخصیص دوبارهٔ همان کانفیگ به شماره‌های دیگر تا زمانی که نشانی‌های یکتا تمام شوند
- تنظیم متن صفحه، فایل APK و تلگرام از پنل
- ثبت شماره و زمان تحویل در پنل، بدون ثبت IP یا نام
- ذخیره‌سازی JSON خصوصی؛ بدون نیاز به دیتابیس یا Node.js

## نکتهٔ مهم دربارهٔ حجم و سهمیه

این روش کانفیگ‌های موجود در یک اشتراک را بین کاربران تقسیم می‌کند؛ کانفیگ تازه نمی‌سازد و برای هر کاربر سهمیهٔ مستقل ایجاد نمی‌کند. محدودیت حجم کلی همان محدودیت اشتراک اصلی است و مصرف کاربران از همان اشتراک کم می‌شود. اگر لازم است هر نفر سهمیه و انقضای جداگانه داشته باشد، پنل سرویس VPN باید API ساخت کاربر/کانفیگ داشته باشد و لازم است آن API به سایت متصل شود.

هر آدرس کانفیگ فقط یک‌بار تخصیص داده می‌شود؛ اگر اشتراک تعداد محدودی آدرس داشته باشد، پس از تخصیص همهٔ آن‌ها هدیه متوقف می‌شود. قالب‌های شناخته‌شدهٔ VLESS، VMESS، Trojan، Shadowsocks، SSR، Hysteria، TUIC و WireGuard پشتیبانی می‌شوند؛ پاسخ اشتراک باید متنی یا Base64 باشد.

## نیازمندی‌ها

- PHP 7.4 یا جدیدتر
- HTTPS فعال
- امکان خروجی HTTPS از سرور cPanel به میزبان اشتراک
- مجوز نوشتن PHP روی storage/data.json و پوشهٔ uploads
- برای آپلود APK بزرگ، مقدار upload_max_filesize و post_max_size هاست باید کافی باشد؛ در غیر این صورت لینک مستقیم وارد کن.
- برای گزارش تلگرام، cURL در PHP یا allow_url_fopen فعال باشد.

## حریم خصوصی و حفاظت

شماره برای جلوگیری از دریافت دوباره ذخیره می‌شود. لینک اشتراک در storage/data.json نگهداری می‌شود و فایل .htaccess دسترسی وب مستقیم به storage را می‌بندد. HTTPS هاست را فعال نگه دار و مطمئن شو پوشهٔ storage قابل دریافت مستقیم نیست. شماره فقط با رضایت کاربر به تلگرام ارسال می‌شود.
