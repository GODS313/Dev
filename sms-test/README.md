# Etebarami SMS Gateway

نسخهٔ آزمایشی مستقل برای نصب زیرمسیر `https://etebarami.net/sms-test/`. هیچ فایل ریشهٔ سایت را تغییر نمی‌دهد. اجزای تحویل‌شده: پنل PHP/MySQL سازگار با cPanel، API دستگاه، مهاجرت اولیهٔ دیتابیس، Cron شبیه‌سازی Test Mode، و سورس اپ Android با حداقل API 26.

> ارسال فقط برای شماره‌هایی که رضایت دریافت پیام برایشان ثبت شده مجاز است. Blocklist هنگام ساخت صف بررسی می‌شود. حالت Test Mode هرگز به گوشی پیام نمی‌فرستد. ارسال واقعی به محدودیت حداقل ۳۰ ثانیه بین پیام‌ها پایبند است.

## نیازمندی‌ها

- PHP 8.1+ با PDO MySQL، OpenSSL، JSON و cURL برای آزمون Telegram
- MySQL یا MariaDB و HTTPS معتبر
- اپ Android نیازمند اجازهٔ `SEND_SMS` است؛ انتخاب سیم در Dual SIM فعلاً پشتیبانی نشده و از SIM پیش‌فرض دستگاه استفاده می‌شود.

## نصب cPanel

1. یک پوشهٔ خالی `public_html/sms-test/` بسازید و ZIP مخصوص cPanel را همان‌جا Extract کنید تا `install.php` مستقیماً در آن پوشه باشد.
2. در cPanel یک دیتابیس و کاربر MySQL بسازید و تمام دسترسی‌ها را به آن بدهید.
3. `https://etebarami.net/sms-test/install.php` را فقط با HTTPS باز کنید؛ پیش‌نیازها را بررسی و دیتابیس و حساب مدیر را وارد کنید.
4. بعد از نصب به صفحهٔ ورود بروید. فایل نصب با `storage/installed.lock` قفل می‌شود. از حذف `app/config.php` خودداری کنید.
5. اگر نصب نیمه‌کاره ماند، پیش از تلاش دوباره، جدول‌های ایجادشده را از دیتابیس آزمایشی پاک کنید یا دیتابیس تازه‌ای بسازید.

## اتصال Telegram

در پنل «تنظیمات و تلگرام»، Bot Token و Admin Chat ID را ذخیره و Test Telegram Connection را بزنید. Token با AES-256-GCM رمزگذاری شده و کلید آن در `app/config.php` است. برای اعلان‌های محیطی، از BotFather توکن بگیرید و ابتدا به ربات پیام دهید تا Chat ID در دسترس باشد. حذف تنظیمات توکن از پنل فعلاً با خالی گذاشتن فیلد انجام نمی‌شود؛ برای تعویض Token مقدار جدید وارد کنید.

## اتصال Android و Pair

1. در پنل از «گیت‌وی‌ها» دستگاه بسازید و کد ۸ رقمی را در کمتر از ۱۰ دقیقه در اپ وارد کنید.
2. سورس `android/` را با Android Studio باز و روی گوشی Android 8+ نصب کنید. آدرس Backend را `https://etebarami.net/sms-test` بگذارید. اینترنت و زمان صحیح گوشی لازم است.
3. شماره سیم‌کارت و نام اپراتور را در صورت تمایل ثبت و مجوز SEND_SMS را تأیید کنید. این نسخه از SIM پیش‌فرض گوشی استفاده می‌کند.
4. پس از Pair، اپ توکن مخصوص Gateway را فقط در preferences خصوصی نگه می‌دارد و heartbeat ارسال می‌کند. پنل دستگاه را Online نشان می‌دهد.
5. دستگاه باید از محدودیت‌های اجرای پس‌زمینهٔ EMUI مستثنا شود: App launch/Autostart و Battery optimization را برای اپ اجازه دهید.

## Test Mode و Test SMS واقعی

- ارسال جدید را با گزینهٔ Test Mode برای بررسی گردش کار بسازید؛ Cron وضعیت آن را شبیه‌سازی می‌کند و SMS واقعی نمی‌فرستد.
- برای ارسال واقعی، شمارهٔ خودتان را در مخاطبان با گزینهٔ رضایت تأییدشده ثبت کنید و مطمئن شوید Blocklist نیست. سپس در «ارسال جدید» بخش «ارسال Test SMS واقعی (یک شماره)» را انتخاب کنید. پیام فقط پس از دریافت دستگاه آنلاین و با مجوز سیستم Android ارسال می‌شود.
- برای کمپین واقعی، فقط شماره‌های داخل فایل که قبلاً به‌عنوان `opted_in` ثبت شده‌اند وارد صف می‌شوند. مخاطب ناشناخته، شمارهٔ مسدود، تکراری و نامعتبر در شمارش جدا گزارش می‌شود.

## Cron cPanel

در cPanel → Cron Jobs یک وظیفهٔ هر دقیقه اضافه کنید. مسیر PHP به هاست بستگی دارد؛ نمونه:

```sh
/usr/local/bin/php -q /home/CPANEL_USER/public_html/sms-test/cron.php
```

مسیر home و PHP را با اطلاعات همان cPanel جایگزین کنید. Cron فقط کمپین Test Mode را شبیه‌سازی و Gatewayهای بدون heartbeat را Offline می‌کند.

## API دستگاه

- `POST /api/gateway/pair`
- `POST /api/gateway/heartbeat` (Bearer token)
- `GET /api/gateway/jobs` (Bearer token؛ هر نوبت حداکثر یک کار)
- `POST /api/gateway/jobs/{id}/sent|delivered|failed` (Bearer token)

Job ID یکتا و callbackها idempotent هستند. ارسال پیامک ذاتاً تضمین exactly-once ندارد؛ خاموش‌شدن گوشی پس از ارسال شبکه‌ای و پیش از callback ممکن است نتیجه را نامعلوم کند. نسخهٔ اولیه کارهای `processing` را خودکار دوباره ارسال نمی‌کند تا از پیام تکراری جلوگیری کند.

## عیب‌یابی

- نصب، خطای HTTPS: گواهی SSL دامنه را فعال کنید.
- PDO MySQL: در MultiPHP Manager / Select PHP Version افزونهٔ `pdo_mysql` را فعال کنید.
- دسترسی ذخیره‌سازی: مالکیت و permission پوشه‌های `app/` و `storage/` را مطابق cPanel اصلاح کنید؛ دسترسی عمومی نوشتن ندهید.
- Pair منقضی: کد تازه از پنل بسازید و دوباره وارد کنید.
- Gateway آفلاین: URL و HTTPS، اینترنت، زمان گوشی، باتری EMUI و ثبت توکن را بررسی کنید.
- SMS ارسال نشد: مجوز SEND_SMS، سیم پیش‌فرض، آنتن، اعتبار سیم‌کارت، محدودیت‌های اپراتور و خطای پیامک را بررسی کنید.
- Telegram ناموفق: Token و Chat ID را بررسی کنید؛ ارتباط خروجی HTTPS و cURL باید فعال باشد.

## چک‌لیست امنیتی

- HTTPS برای تمام دسترسی‌ها الزامی است؛ از TLS معتبر استفاده کنید.
- رمز مدیر با `password_hash` نگهداری، Session امن و درخواست‌های فرم دارای CSRF هستند.
- API از SHA-256 توکن Gateway، جست‌وجوهای PDO آماده، و رویدادهای قابل ممیزی استفاده می‌کند.
- فایل‌های تنظیمات و storage با `.htaccess` بسته شده‌اند؛ فهرست‌کردن دایرکتوری غیرفعال است.
- از رمز مدیر منحصربه‌فرد و طولانی استفاده کنید؛ ZIP و فایل نصب را پس از نصب از مسیر عمومی حذف کنید.
- پیش از استفادهٔ عملی، backup دیتابیس و فایل تنظیمات را خارج از webroot نگه دارید. توکن‌ها را افشا نکنید.

## محدودیت نسخهٔ آزمایشی

این بسته مرحلهٔ اول است. ساخت و نمایش صف، پنل، ورود، تنظیم Telegram، Pair، heartbeat، Import فایل در فرم کمپین و Test SMS یک‌گیرنده را فراهم می‌کند. گروه‌بندی کامل، CSV export، انتخاب SIM دوگانه، webhookهای رویدادی Telegram و APK امضاشده در این نسخه آماده نیستند. تست cPanel، ارسال واقعی و build APK نیازمند میزبان/دستگاه واقعی است.
