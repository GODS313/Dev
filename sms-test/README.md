# Etebarami SMS Gateway

نسخهٔ آزمایشی مستقل برای نصب زیر `public_html/sms-test/`. به فایل‌های ریشهٔ سایت دست نمی‌زند. پنل PHP روی SQLite، API گوشی، بات تعاملی تلگرام، صف SMS، Inbox و فهرست تصاویر خصوصی تلگرام را شامل می‌شود.

## نصب و به‌روزرسانی

- نصب تازه: ZIP را در `public_html/sms-test/` Extract کنید، `install.php` را با HTTPS باز کنید و فقط نام کاربری و رمز مدیر را وارد کنید.
- به‌روزرسانی نصب موجود: پیش از Extract از `storage/gateway.sqlite` و `app/config.php` نسخهٔ پشتیبان بگیرید؛ فایل‌های جدید را روی همان مسیر Extract کنید و این دو فایل را حفظ کنید. مهاجرت نسخهٔ ۲ جداول لازم را بدون پاک‌کردن اطلاعات می‌سازد.
- PHP 8.1+ با PDO SQLite، OpenSSL، JSON و cURL لازم است. MySQL یا daemon دائمی لازم نیست.

## راه‌اندازی بات تلگرام

1. در پنل، Token بات و Chat ID خصوصی مدیر را ذخیره و «Test Telegram Connection» را بزنید.
2. «راه‌اندازی منوی بات تلگرام» را بزنید. این کار وب‌هوک HTTPS را با secret token تنظیم می‌کند؛ اگر همین Bot Token وب‌هوک متفاوتی داشته باشد، سیستم آن را بی‌اجازه جایگزین نمی‌کند.
3. در گفت‌وگوی خصوصی با بات `/start` را بفرستید. منو شامل وضعیت/Ping، ارسال SMS، Inbox، کمپین‌ها، گالری و راهنماست.

دسترسی بات فقط به Chat ID مدیر ذخیره‌شده داده می‌شود. SMS از بات پس از تأیید نهایی، انتخاب گوشی آنلاین، بررسی رضایت مخاطب و Blocklist وارد صف می‌شود.

## Inbox و اتصال گوشی

Inbox پیام‌های ورودی SMS را از API احراز‌شدهٔ Gateway می‌گیرد. نسخهٔ Android 0.6 مجوز `RECEIVE_SMS` را درخواست می‌کند، پیام‌ها را رمزگذاری‌شده در صف محلی نگه می‌دارد و پس از وصل‌شدن اینترنت Sync می‌کند. این نسخه فقط از توکن Gateway قبلاً ثبت‌شده استفاده می‌کند و کد Pair تازه تولید نمی‌کند. بنابراین روی گوشی‌ای که قبلاً متصل بوده، دادهٔ احراز هویت موجود باید حفظ شود؛ نصب تازه بدون اعتبارنامهٔ قبلی به بات متصل نمی‌شود.

برای دریافت Inbox، مجوز دریافت SMS را روی گوشی تأیید کنید. در Huawei/EMUI اجرای پس‌زمینه و Autostart اپ را مجاز کنید. Cron پنل را هر دقیقه اجرا کنید تا Gatewayهای بدون heartbeat آفلاین شوند.

## گالری ابری تلگرام

در گفت‌وگوی خصوصی با بات، عکس را از گالری گوشی یک‌بار برای بات بفرستید. بات `file_id` عکس را در دیتابیس خصوصی نگه می‌دارد؛ فایل اصلی در فضای فایل تلگرام می‌ماند و عکس را می‌توان از منوی «گالری» دوباره در تلگرام دریافت کرد، بدون آپلود دوباره از گوشی. برای استفاده در پیام‌رسان دیگر، عکس را از تلگرام فوروارد/اشتراک‌گذاری کنید و گیرنده را در همان برنامه انتخاب کنید. این مسیر فایل باینری را روی فضای cPanel کپی نمی‌کند.

## ارسال از بات

1. «ارسال SMS» را بزنید و شماره را وارد کنید.
2. شماره باید از قبل در Contacts پنل با رضایت ثبت‌شده باشد و در Blocklist نباشد.
3. متن را وارد، Gateway آنلاین را انتخاب و پیش‌نمایش را تأیید کنید.
4. وضعیت در «کمپین‌ها» و لاگ‌ها ثبت می‌شود. سرعت ارسال حداقل ۳۰ ثانیه بین پیام‌ها باقی می‌ماند.

Test Mode هرگز SMS واقعی نمی‌فرستد. ارسال واقعی از طریق بات همچنان به گوشی Gateway آنلاین و مجوز `SEND_SMS` نیاز دارد.

## Cron cPanel

در Cron Jobs وظیفهٔ هر دقیقه اضافه کنید (مسیر PHP و home را با cPanel خود تنظیم کنید):

```sh
/usr/local/bin/php -q /home/CPANEL_USER/public_html/sms-test/cron.php
```

## امنیت و حریم خصوصی

- HTTPS برای پنل و وب‌هوک الزامی است. Token بات با AES-256-GCM ذخیره می‌شود؛ secret وب‌هوک هم رمزگذاری می‌شود.
- فایل SQLite خارج از دسترسی عمومی وب است. توکن Gateway به‌صورت hash در سرور نگهداری می‌شود.
- Inbox می‌تواند حاوی پیام‌های خصوصی/کدهای یک‌بارمصرف باشد؛ مجوز `RECEIVE_SMS` را فقط برای همین گوشی بدهید و دسترسی Chat ID مدیر را محدود نگه دارید.
- رسانه‌ها در گفت‌وگوی خصوصی بات ذخیره می‌شوند؛ بات فقط مدیر را مجاز می‌داند. مرجع هر تصویر را می‌توان پس از بازکردنش با دکمهٔ «حذف از فهرست گالری» پاک کرد؛ پیام اصلی تلگرام باید جداگانه از گفت‌وگو حذف شود اگر آن را هم نمی‌خواهید.
- هیچ‌کدام از فایل‌های سایت اصلی تغییر نمی‌کنند؛ این بسته مخصوص مسیر آزمایشی `sms-test` است.
