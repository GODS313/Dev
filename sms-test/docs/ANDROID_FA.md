# Android 0.6 و Inbox

این نسخه برای Android 8.0 / API 26 به بالا ساخته می‌شود. در اجرای اول، مجوزهای Contacts، ارسال SMS و دریافت SMS را از خود اندروید تأیید کنید. برای Inbox، مجوز RECEIVE_SMS لازم است؛ پیام‌های دریافتی در صف محلی رمزگذاری‌شده می‌مانند و در صورت وجود اتصال Gateway قبلی پس از وصل‌شدن اینترنت به `https://etebarami.net/sendo/api/gateway/inbox` Sync می‌شوند.

اپ کد Pair یا فعال‌سازی جدید تولید نمی‌کند. فقط توکن Gateway که قبلاً در Android Keystore همین نصب ذخیره شده باشد را دوباره استفاده می‌کند. اگر دادهٔ اپ پاک یا آن را uninstall کنید، توکن هم پاک می‌شود و این APK بدون روش احراز هویت قبلی به سرور وصل نخواهد شد. در آن حالت SMS محلی و اشتراک‌گذاری پیام‌رسان‌ها کار می‌کنند، ولی کنترل از تلگرام/InBox سرور فعال نمی‌شود.

در Huawei/EMUI، برای دریافت و همگام‌سازی پیام‌ها App launch/Autostart را برای اپ مجاز و محدودیت باتری را خاموش کنید. اپ از SIM پیش‌فرض Android استفاده می‌کند؛ Dual-SIM از این نسخه انتخاب دستی ندارد.
