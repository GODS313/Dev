# نصب و اتصال Android Gateway

اپ برای Android 8.0 / API 26 به بالا ساخته می‌شود. APK آزمایشی شناسهٔ جداگانه دارد و کنار اپ `/sendo` نصب می‌شود؛ آدرس آن `/sms-test` است. در اجرای اول، مجوز Contacts، ارسال SMS و دریافت SMS را از خود Android تأیید کنید. برای Inbox، `RECEIVE_SMS` لازم است؛ پیام‌ها تا زمان Sync به‌صورت رمزگذاری‌شده در گوشی صف می‌شوند.

اگر توکن قبلی در Android Keystore همین نصب موجود باشد، اپ همان نشست را استفاده می‌کند. اگر به‌دلیل تفاوت امضای APK نصب تازه لازم شود، اپ بدون نمایش یا واردکردن کد، درخواست امن می‌فرستد. در بات مدیر، دستگاه را به Gateway قبلی متصل و با یک دکمه تأیید کنید. توکن جدید از HTTPS دریافت و در Android Keystore ذخیره می‌شود.

در Huawei/EMUI، برای Sync پس‌زمینه Autostart اپ را مجاز و محدودیت باتری را خاموش کنید. ارسال با SIM پیش‌فرض Android انجام می‌شود؛ انتخاب دستی SIM دوگانه در این نسخه نیست.

برای اینکه نصب‌های بعدی بدون حذف اپ انجام شوند، یک Release keystore پایدار بسازید و همان را در GitHub Actions Secrets با نام‌های `ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS` و `ANDROID_KEY_PASSWORD` تنظیم کنید. این کلید را امن نگه دارید و در بیلدهای بعدی عوض نکنید. کلید امضای APK آزمایشی ۰٫۵ در دسترس پروژه نیست؛ نصب اولیهٔ نسخهٔ جدید به همین دلیل فقط یک‌بار تأیید اتصال از بات می‌خواهد.
