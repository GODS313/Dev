# نکات امنیتی

- HTTPS معتبر، رمز مدیر قوی و دسترسی محدود فایل‌ها را حفظ کنید.
- `app/config.php` کلید رمزگذاری Token بات و secret وب‌هوک را دارد؛ آن را در اختیار دیگران نگذارید.
- وب‌هوک Telegram فقط درخواست دارای secret header معتبر و پیام خصوصی از Admin Chat ID ذخیره‌شده را می‌پذیرد.
- توکن Gateway به‌صورت hash در سرور نگهداری می‌شود و صف محلی Inbox در Android با Android Keystore رمز می‌شود.
- Inbox حاوی متن SMSهای ورودی است و ممکن است کدهای یک‌بارمصرف را نیز شامل شود؛ آن را فقط برای گوشی و مدیر مورد اعتماد فعال کنید.
- تصاویر ارسالی به بات به‌صورت Telegram `file_id` در فهرست گالری ثبت می‌شوند و فایل باینری روی cPanel ذخیره نمی‌شود. بات فقط مدیر را مجاز می‌داند.
- درخواست اتصال تازهٔ Gateway فقط با راز تصادفی طولانی‌مدت و تأیید Chat ID مدیر پذیرفته می‌شود؛ راز polling به‌شکل hash و توکن صادرشده به‌شکل رمزگذاری‌شده در سرور می‌ماند.
- ارسال واقعی فقط پس از تأیید صریح، برای شمارهٔ دارای رضایت ثبت‌شده و خارج از Blocklist انجام می‌شود. محدودیت فاصلهٔ ارسال را برای دورزدن محدودیت اپراتور تغییر ندهید.
