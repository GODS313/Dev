# نکات امنیتی

- HTTPS معتبر، رمز مدیر قوی و دسترسی محدود فایل‌ها را حفظ کنید.
- فایل `app/config.php` شامل کلید رمزگذاری است؛ آن را در اختیار دیگران نگذارید.
- توکن Gateway پس از Pair فقط در اپ نگه‌داری می‌شود؛ برای باطل‌کردن، Gateway را غیرفعال کنید یا توکن تازه بسازید.
- برای استفادهٔ واقعی، رضایت مخاطب را خارج از این سامانه مستند کنید و درخواست opt-out را فوراً وارد Blocklist کنید.
- Test Mode هیچ پیام واقعی نمی‌فرستد. تست واقعی فقط یک گیرنده دارد.
- ارسال واقعی با فاصلهٔ محافظه‌کارانه انجام می‌شود و نباید برای دور زدن محدودیت‌های اپراتور تغییر یابد.
