# راهنمای نصب روی cPanel

ZIP را داخل پوشهٔ خالی `public_html/sms-test` Extract کنید؛ فایل `install.php` باید مستقیماً داخل همین پوشه باشد. دیتابیس MySQL و کاربر آن را از cPanel بسازید و دسترسی کامل بدهید. سپس `https://etebarami.net/sms-test/install.php` را باز کنید، سازگاری را بررسی و اطلاعات مدیر و دیتابیس را وارد کنید.

پس از نصب با نام کاربری و رمز ساخته‌شده وارد شوید. نصب فقط روی HTTPS فعال می‌شود و پس از موفقیت قفل خواهد شد. سطح دسترسی‌های پوشه‌ها را در حالت محدود نگه دارید.
